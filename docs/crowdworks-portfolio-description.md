# CrowdWorks ポートフォリオ掲載用説明文 — 湯宿 山霞

## 作品タイトル

架空温泉旅館「湯宿 山霞」ブランドサイト — 自作GLSLシェーダーによる没入表現(Concept Project)

## 短い説明(100文字程度)

架空の温泉旅館のブランドサイトです。ライブラリを使わない素のWebGL2と手書きGLSLで、スクロールに反応する霞の谷と「触れると波紋が広がる水面」を実装しました。

## 詳細な作品説明

山あいの温泉旅館を題材にした、架空ブランドのコンセプトサイトです。企画・コピー・デザイン・シェーダー実装・フォーム・テストまでを一人で担当しました。

最大の特徴は、Three.js等の3Dライブラリを使わず、素のWebGL2と手書きGLSLシェーダー4本で世界観を描いていることです。

- ヒーローの夜の谷(稜線・霞・月・灯り)はすべてノイズ関数による手続き生成。スクロールするほど霞が薄れ、宿の灯りがともります(コピー「霞の向こうに、湯の灯り。」の実装)
- 露天風呂の水面は波動方程式のリアルタイムシミュレーション。なぞると波紋が広がります
- 湯けむりはノイズを歪ませた蒸気表現

演出偏重にならないよう、reduced-motion対応(静止画に切替)、WebGL非対応環境へのフォールバック、画面外での描画停止、モバイルの負荷制御(解像度上限)を実装し、情報はすべてDOMテキストで完結させています。宿泊予約フォームは境界値検証を含むフロントエンドバリデーション付きです。

「湯宿 山霞」は実在しない架空の宿であり、その旨をサイト内に明記しています。

## 工夫した点

- 波動方程式をピンポンFBOで解く水面シミュレーション(触れると波紋、無操作でも湯口の雫で水面が生きている)
- スクロール量をシェーダーのuniformに接続し、「ページを下る=宿にたどり着く」物語をGLSLで実装
- 没入表現に必須のガード一式: reduced-motion静止化・WebGL非対応フォールバック・画面外停止・DPR上限
- canvasはすべて装飾扱い(aria-hidden)とし、情報はDOM側で完結(アクセシビリティと両立)

## レスポンシブ対応

360 / 375 / 768 / 1024 / 1440px で検証済み。シェーダーは画面幅に自動追従し、モバイルでは解像度上限で負荷を抑えています。
