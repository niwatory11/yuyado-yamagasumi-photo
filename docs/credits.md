# 写真素材のクレジット

本サイト(写真併用版)で使用している画像素材の出典一覧です。
部屋「灯」「霞」の2点は商用利用可のCCライセンスで公開されている実写素材を、**「夜山×灯火」トーンへの色調加工(彩度調整・カラーグレーディング・クロップ・ビネット)のうえ**使用しています。加工後の画像も各ライセンスの条件(継承条項を含む)に従います。
部屋「谺」と料理・宿についての3点は、`docs/image-generation-prompts.md` のプロンプトで生成した**画像生成AI(ChatGPT / GPT Image)による生成イメージ**です(クロップ・WebP変換のうえ使用)。
写真はすべてイメージであり、架空の宿「湯宿 山霞」とは関係ありません。
