# 写真素材のクレジット

本サイト(写真併用版)で使用している実写素材の出典一覧です。
いずれも商用利用可のライセンスで公開されているものを、**「夜山×灯火」トーンへの色調加工(彩度調整・カラーグレーディング・クロップ・ビネット)のうえ**使用しています。加工後の画像も各ライセンスの条件(継承条項を含む)に従います。写真はすべてイメージであり、架空の宿「湯宿 山霞」とは関係ありません。
